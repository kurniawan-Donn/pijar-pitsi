STRUKTUR WEBSITE SISTEM INFORMASI MAGANG

Folder ini berisi struktur folder yang sudah dirapikan untuk project Laravel.

Catatan:
- Ini hanya struktur folder, bukan project Laravel lengkap.
- Jika kamu sudah punya project XUPING-AFA, gunakan struktur ini sebagai acuan.
- Jangan hapus controller/model lama sebelum kita cek apakah masih digunakan.

Struktur utama:
app/Http/Controllers/
  Admin/
  Auth/
  SuperAdmin/
  Website/

resources/views/
  website/
  auth/
  admin/
  superadmin/

database/
  migrations/
  seeders/
  factories/

Langkah berikutnya:
1. Masukkan struktur ini ke project Laravel yang sudah ada.
2. Kita buat Controller dan Model menggunakan perintah Laravel.
3. Setelah itu baru kita buat tampilan website one-page.
